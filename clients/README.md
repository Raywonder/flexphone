# Flex Phone Clients

Platform-native clients live here so Flex Phone stays separate from Flex PBX server code and VoiceLink chat/rooms code.

## Layout

- `windows/native/` - native Windows WPF client.
- `macos/native/` - native macOS client work. Use Swift/AppKit or SwiftUI here when the macOS version is built.

Shared protocol notes and backend contracts can stay in the root README or platform README files when both clients use them.
