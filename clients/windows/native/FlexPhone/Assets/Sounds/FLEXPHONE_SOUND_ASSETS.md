# Flex Phone Desktop Sound Assets

These bundled assets came from `E:\Downloads\FlexPhoneSounds` for the next Flex Phone release.

## Action Mapping

- `incoming-ring.wav` uses `Incoming Call.wav` and is played for incoming calls.
- `quick-alert.wav` uses `Flex Phone Softphone.wav` and is played for short status/action alerts.
- Existing `call-connected.wav`, `call-ended.wav`, and `network-change.wav` remain mapped to their current actions.

## Ringtone Choices

Additional ringtone choices are included under `Ringtones/`:

- `ringtone-incoming-call.wav`, 6.00 seconds.
- `ringtone-incoming-call-alt.wav`, 7.12 seconds.
- `ringtone-ring-ring-flitch.wav`, 16.12 seconds.
- `ringtone-are-you-gonna-answer.wav`, 20.28 seconds.

All listed files are stereo 48 kHz 16-bit PCM WAV and are included by the project `Assets\**` resource rule.
