# Flex Phone Native for macOS

This subtree is reserved for the native macOS Flex Phone client.

Use this folder for Swift/AppKit or SwiftUI code that matches the Windows native client behavior:

- Flex PBX account linking and remembered sign-in.
- Multi-line calling, DTMF, hold, transfer, voicemail, queue status, DND, and call screening controls.
- VoiceOver-first accessibility with clear names, roles, values, focus order, and status announcements.
- Native macOS packaging and update flow.

Do not place VoiceLink chat/rooms code or Flex PBX server modules in this subtree.
